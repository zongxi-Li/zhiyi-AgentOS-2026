## 设计遗漏与修正

1. E 把 metadata.outputRef/outputSummary 提升到 entry 顶层，会破坏 TaskEditor 的既有读取路径。改为同名 `metadata` 字段承载显式 WorkspaceEntryMetadataQuery，不扩散 Role 自由 JSON 例外。
2. E 宣称 runtimeStatus/taskPlanVersion 等可删，但 Inspector 与 Sidebar 有实读；artifactProjection.ts 另消费分类标识、证据/上游/trace 引用和 confidence。现库只出现两键不能证明这些生产与消费路径无效。先产出逐字段生产者、消费者、类型、公共性表，再定白名单。
3. diagnostics.details 不止 deferred 规划分支：还有缺少交付物、缺失任务绑定、计划任务缺失、legacy Artifact、历史 plan snapshot 未解析等分支。全部公开标识、计数和状态应以显式 typed details 字段表达；不包装 TaskPlan、Object、Map 或任意 JSON。
4. GraphQuery 不同构的判断成立。WorkspaceGraphQuery 节点/边复用 GraphNodeQuery/GraphEdgeQuery；导航 graphNodes 的结构另行保留，不能复用同名却不同形状的节点 DTO。复用纯 node/edge/display Mapper 时避免复制规则；不得因此重写现有 Run 图响应。
