# 知弈 AgentOS 文档索引

本目录按 **为什么做 → 做成什么 → 怎么实现 → 如何演示** 组织。建议新成员先读本页的「原生运行（N03）」，
再按需进入架构与开发记录。

当前运行形态：**Windows 11 原生持久栈（N03）**——本机 PostgreSQL 15.19 + Memurai + Java/Python/Vite +
Electron，不再使用 Docker。依赖准备、`init/up/status/down`、数据布局、冷备份与恢复见
[N03 运行说明](../ops/scripts/infra/windows/native/README-N03.md)。
Docker 时代的 RFC、实施与验收文档作为历史证据保留，不再代表当前运行方式。

文档分为三种性质：

- **当前基线**：描述当前仍然有效的架构、边界和操作方式。
- **阶段证据**：记录某个阶段实际做了什么、如何验证以及当时的结论；用于审计和追溯，不替代当前基线。
- **设计归档**：保留早期设想和演进过程，不作为当前能力承诺。

## 维护约定

1. 架构决策放入 `架构设计/`，阶段实施与验收证据放入 `开发记录/`。
2. 面向展示的报告与素材放入 `演示与交付/`，早期设计稿放入 `superpowers/` 归档。
3. 阶段报告一旦形成审计证据，不用后续结论覆盖原文；在本索引中标注其历史状态。
4. 原生运行操作说明与脚本就近存放在 `ops/scripts/infra/windows/native/`，本索引只建立入口。
5. 新增文档时同步更新本索引，并注明日期、适用平台、验证范围和结论状态。
