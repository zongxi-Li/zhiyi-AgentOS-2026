## 3. 类型与语义规则

- **必须对象**：usage/contextPressure/composition（总览）、usage（calls 行）、items（页信封）缺失/null/错型 → contract invalid（502），不得伪装成空数据（依据：Sidebar `resourceUsage?.usage.callCount` 与 Inspector `props.usage?.composition.materialFragmentCount` 无内层守卫，缺对象会 TypeError；items 缺失伪装空页会掩盖上游断裂）。
- **精确计数**：token 合计/latency 用 long（长 Run 可超 int 范围，测试含 3e9 边界）；计数用 int。转换走 BigDecimal exact（Float/Double 先按 binary64 精确构造，不经十进制字符串二次舍入——沿 E2 修正模式）；小数计数拒绝舍入（ArithmeticException → 同一 502 信封）。
- **比例**：cacheHitRatio/current/peak/taskProgress/行内 contextPressure 只接受有限数（QueryWire.decimal 的 isFinite 检查），NaN/Infinity → contract invalid，不伪造 0。
- **分页**：nextCursor 原样透传（text，不解析不重写）；total 为上游过滤后总数；pageSize 默认 20，stepId/cursor 为 null/空白时不进查询串（AgentOsPaths.query 原语义）。
- **上游校验顺序**：`load_run` 先于 cursor 解析，故不存在 run 的非法 cursor 也是 404——保留上游原语义，未在 Java 侧重排。
