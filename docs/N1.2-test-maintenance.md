# N1.2 测试整理

## 合并重复守卫

IdentityProjectionArchitectureTest、MissionProjectionArchitectureTest 和新增 Run 通用守卫重复实现 DTO 类型闭包与 Mapper 纯度扫描。整理为一个 QueryProjectionArchitectureTest，统一覆盖：

- 全部已存在及未来新增 `projection/**/dto` 文件的字段、getter、父类、泛型、数组与 sealed 子类。
- Entity、内部模型、Map/Object/JsonNode、raw/wildcard 类型和未批准的开放序列化方式。
- 密码、执行状态、checkpoint、scheduler、binding、compiled package、graph patch 与控制帧字段。
- RoleConfigurationQuery 只出现在既有 Role 配置槽，禁止向其他 Projection 扩散。
- 全部 `projection/**/mapper` 的基础设施依赖、反射式转换和写入调用。
- 真实 Controller handler 的 User/Role Entity 返回禁令；其他未迁移接口未被假装纳入严格守卫。

保留嵌套 Entity、动态容器、继承、getter、raw/wildcard、checkpoint 和配置扩散的负例。MissionProjectionArchitectureTest 仅保留其独有的 GET 路由和返回契约检查；删除重复递归实现。Credential 序列化、HTTP/权限/错误、审核命令与 SSE 生命周期测试保留。

## 更新过期契约夹具

前端 Run、Graph、资源观察和能力面板夹具改用公共 review/outputs/lineage/resourceUse/lifecycles。删除要求读取 runtime executionState、executionBinding、compiled package、controlFrames 和 graphPatchRefs 的旧断言，改为验证对应公共事实。

保留 provenance 两种数据来源、token 节省指标、产物读取、审核目标、未知资源能力、Run 切换竞态与取消行为的测试。没有通过跳过测试、删除失败用例或降低运行时错误处理断言使回归通过。

## 验证原则

删除或重命名 Java 测试后执行 `mvn clean test`，避免旧 target/test-classes 导致已删除的测试继续运行。前端执行全量 Vitest 与生产构建。历史迁移文档中的数量是当时提交的结果；当前测试结果以本次清理后的全量执行为准。

本次结果：后端 `mvn -B -ntp clean test` 340 项通过，零失败/错误/跳过，生产包构建通过。前端全量 85 个文件 / 552 项通过；最后一轮删除失效展示组件、资源字段白名单和展示名称整理后，相关 7 个文件 / 51 项再次通过，Web 与 Desktop 类型检查及生产构建通过。未执行真实浏览器、桌面 WebView 或部署环境验收。

首次 Web 构建遇到 Windows 系统临时目录中 esbuild 临时文件删除被拒绝；仅为构建进程设置项目内专用 TEMP/TMP 后重试通过，未改项目依赖、构建脚本或清理系统临时目录。
