# 知弈 AgentOS 公开首页与认证页视觉改造设计

## 目标

新增一个无需登录即可访问的品牌首页，并按 `登录.png`、`首页.png` 的视觉方向重做登录/注册页。首页使用 `frontend/public/bg.jpeg` 作为全屏背景，登录后的业务工作台 `/chat` 保持现有功能和路由不变。

## 路由与应用边界

- `/` 改为公开的 Landing 页面，不触发认证校验。
- `/login` 继续承载登录与注册 Tab，并保留现有登录、注册 API、表单校验、Token 写入和重定向逻辑。
- 登录成功默认进入 `/chat`；如果 URL 带有安全的 `redirect` 查询参数，则继续回到该地址。
- `/chat` 及其他现有业务路由不做业务逻辑重构。
- 应用壳层在 `/` 和 `/login` 上不显示登录后侧边栏、顶栏和运行状态组件，避免公开页面被工作台布局包裹。

## 公开首页设计

Landing 页面作为独立 Vue 视图：

- 背景：`/bg.jpeg`，覆盖整个视口；使用轻微的白色渐变遮罩保证文字对比度。
- 顶部：左侧 `logo.png`、品牌名“知弈 AgentOS”；中间提供“首页 / 功能 / 生态 / 关于”锚点导航；右侧保留英文品牌标语。
- Hero：左侧展示英文小标题“DYNAMIC HETEROGENEOUS AGENT SWARM”、主标题“知弈 AgentOS”、中文副标题和一句产品价值说明。
- 能力点：展示多智能体协作、动态任务规划、异构资源调度、自进化学习四项能力，使用 Element Plus 图标而非 emoji。
- CTA：点击“探索知弈 AgentOS”进入 `/login`。
- 背景主体：不额外覆盖大型图片或 Canvas，让 `bg.jpeg` 中央的智能体球体自然成为视觉焦点；在主体周围用轻量浮动信息卡增强参考图的产品感。
- 交互：导航点击平滑滚动到对应区块；公开首页的非核心区块使用简短的功能、生态和关于内容，避免做成未接入业务的伪功能。

## 登录与注册设计

登录页和注册页共用同一个 `LoginView.vue`：

- 背景：同样使用 `/bg.jpeg`，通过右侧白色渐变和卡片投影降低背景主体对表单的干扰。
- 顶部：品牌 Logo 与“知弈 AgentOS”，右上角显示“More Agents · More Possibilities”。
- 桌面端：左侧为品牌标题、产品能力摘要；右侧为半透明白色玻璃卡片。
- 卡片：欢迎标题、说明、登录/注册切换 Tab、表单字段、记住我、忘记密码入口、渐变主按钮、第三方登录占位入口和隐私提示。
- 注册：沿用当前用户名、邮箱、密码、确认密码字段和校验规则；注册成功后切回登录 Tab 并自动填充用户名。
- 兼容性：忘记密码和第三方登录如果当前没有后端能力，保持视觉入口但明确为不可用或给出提示，不虚构成功流程。
- 响应式：宽度小于 820px 时隐藏左侧大段品牌文案和非必要装饰，卡片占据主要宽度；保证输入框、Tab、按钮触控区域不小于 44px。
- 可访问性：保留显式表单语义、键盘 Enter 提交、可见焦点态、错误信息就近显示、减少动画设置和有意义的按钮标签。

## 组件与实现边界

- 新增 `frontend/src/views/LandingView.vue`，只负责公开首页展示和 `/login` CTA 跳转。
- 将现有 `LoginView.vue` 改为新的视觉结构，但复用当前认证状态与 API 逻辑。
- 路由守卫增加公开首页的正常渲染路径，并调整 `App.vue` 使 Landing/Auth 页面脱离登录后应用壳层。
- 不修改后端认证接口，不迁移图片资源，不删除现有 ACG 登录演示组件前提下可移除其在登录页的展示引用。

## 验证方案

- 新增路由/视图测试，验证未登录访问 `/` 不跳转到 `/login`，点击 CTA 可进入登录页。
- 保留并运行现有前端 Vitest 测试。
- 使用 Node 执行 `npm run build:web`，确认 TypeScript、Vue 模板和 Vite 构建通过。
- 通过本地开发服务器检查 `/`、`/login` 的 HTTP 响应和静态背景资源可访问性。
