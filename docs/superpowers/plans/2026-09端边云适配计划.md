## 1. AgentOS 端边云适配第一阶段实施计划

来源文件：`2026-09-01-agentos-edge-cloud-adaptation.md`

> **给智能体执行者的要求：** 必须使用子技能 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按本计划逐项执行。步骤使用复选框（`- [ ]`）跟踪。

**目标：** 将本地 Agent 资源调度扩展为可表达终端/边缘/云端、支持远程观测、执行适配器调用和基础故障切换的端边云运行链路。

**架构：** 保留现有 `ResourceService`、`SchedulerService`、租约和 `WorkflowRuntime`，在共享合同中增加部署层级、端点和算力约束。调度器只负责选择并冻结执行目标，新增 `ExecutionAdapter` 接缝负责本地或 HTTP 调用；远程心跳由资源节点主动上报。

**技术栈：** Python 3、Pydantic、pytest、FastAPI/HTTPX（沿用现有 AgentOS 测试栈）、SQLite、Redis 租约协调。

## 11. Node/Agent 资源台账迁移实施计划

来源文件：`2026-09-11-node-agent-resource-ledger-migration.md`

> **给智能体执行者的要求：** 必须使用子技能 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按本计划逐项执行。步骤使用复选框（`- [ ]`）跟踪。

**目标：** 将 Node/Agent 台账作为资源调度的持久化数据源，同时继续以兼容性投影形式提供旧 Resource 响应。

**架构：** 为 Node 和 Agent 添加 SQLite 存储，通过 Node 凭据提供器复用现有 HMAC 资源签名协议；让调度器联合评估 Agent/Node 配对；升级租约以绑定 `agentId + nodeId`，同时保留 `resourceId` 作为兼容字段。

**技术栈：** Python 3.11、FastAPI、Pydantic 2、SQLite、Redis Lua 协调器、pytest。

#### 资源器实现说明

资源器由 Node、Agent 和调度器组成：Node 表示实际机器或服务节点，保存算力、模型、显存、隐私和心跳状态；Agent 表示可执行的能力角色，声明能力以及允许使用的节点。调度器把步骤要求、Agent 约束和 Node 状态联合筛选，选出 `agentId + nodeId`，再通过 Redis/CAS 租约占用容量；远程节点通过签名心跳更新状态，旧 Resource 接口仅作为兼容投影。
