🧩

6 类节点 + 7 类边

Step / Agent / Skill / Memory / Evidence / Control 全部入图，依赖、通信、控制、读写、证据支撑建模为边。

🔗

DEPENDENCY 唯一定序

只有依赖边参与执行 DAG，其余边交由通信器 / 记忆器 / 审计器分别消费。

⚡

就绪集并行调度

关键路径取代线性串行，加速比上界 = 总工作量 / 关键路径，受并行度截断。

♻️

存量升格 + GraphPatch

线性流程零改动升格为 ACG；review barrier 上做版本化、不可变拓扑修补。

O(N+E)
环检测 · 拓扑排序（规划交付前一次性验证）
关键路径
并行执行时长上界，替代 Σ 串行耗时
🔀

执行与数据解耦

「谁先执行」与「数据 / 记忆 / 证据给谁」解耦 —— 同一张图既是执行计划，又是血缘图谱。

◆

图是唯一的执行真源：既决定「先做什么」，又记录「谁影响了谁」—— 计划与证据在此合一。

低熵通信

🛰️

📋

📦

最小 ContextPack

只传结构化数据、不传对话全文，下游仅取所需字段，复杂度 O(F)。

🪢

记录数据诞生（校验和）与消费，前向「从何而来」+ 后向「用在何处」。
