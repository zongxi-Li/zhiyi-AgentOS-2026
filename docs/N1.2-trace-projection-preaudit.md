## 0. 结论

1. **信封与事件骨架可以完全 typed**：7 键信封 + 9 键事件骨架字段全部有稳定生产合同，可按既有投影模式迁移。
2. **payload 无法在不丢失既有展示的前提下用纯有限字段表达**。核心冲突：`runtimePresentation.ts` 的 generic 分支遍历 payload 全部键渲染详情（`runtimePresentation.ts:397`），且 `_redact` 会在任意深度把键名含标记词的叶子替换为字符串 `"[redacted]"`（如 `usage.input_tokens`、`promptVersion`），有限 typed 字段无法同时容纳这两点。
3. 推荐方案：**已知读取键 typed 字段 + 有界 extras 键值列表**（详见 §5 方案 A）。该方案不引入 Map/JsonNode/Object 字段，不扩大 Role JSON 例外，前端只需一处小改（generic 分支展开 extras）。
4. 三项待裁决（§8）：payload 表示方案、已知键类型不符时的降级策略、`str(exc)` 观察文本现状保留。

## 4. 字符串内容审计

**公开正文（设计上即面向用户，区分依据 = 生产者白名单本身，不需要正则猜语义）**：`observation`、`message`、`comment`（审核评语，[:500]）、`reason`（[:500]）、`outputSummary`（节点产物摘要）、`summary`、`notes[]/selectionReasons[]`、`safeSummary`。来源全部是运行时文案、用户评语或模型产物摘要。

**内部控制数据（已在 wire 上、前端 generic 详情现状可见，属审计元数据而非正文）**：`promptAudit`（键为模板 hash/版本/信任摘要，无 prompt 正文——`model_runtime.py:226` 构造自 `safe_prompt_metadata` 白名单）、`topologyAudit`（`_safe_topology_audit` 封闭 schema）、`profile`（任务语义画像）、`pluginSnapshot`、各类 hash/version/fingerprint。若评审认为 generic 详情不应展示这些，属展示策略裁决，不是本轮迁移引入。

**风险点（如实登记）**：`workflow_runtime.py:2066/2073` 的 `observation=str(exc)` 是无界异常文本——Python 内部异常（含文件路径、类名、KeyError repr）可能进入 wire，仅受 `_redact` 2000 字符截断。现状前端已显示。预审建议**现状保留**（迁移不改语义），生产端收敛单独立项。

**正文边界（已核实不泄漏）**：模型输出正文 `data` 在生产端剥离（native.py:358-365）；`delta` 片段被 workspace 视图过滤，planner 侧 delta 事件 `persistTrace: False` 不落 trace；`pendingMemory` 只携带引用与策略；`communicationReads` 白名单注释明确排除 reason 与正文。

**[redacted] 标记值**：键名启发式会误伤正常键（`usage.input_tokens`、`promptVersion`、`promptTemplateHash` 等），这些叶子在 wire 上是字符串 `"[redacted]"` 而非原类型。typed 设计必须容忍（见 §5）。

## 5. typed 设计方案（待裁决核心）

### 方案 A（推荐）：已知键 typed + 有界 extras

```
TraceQuery(runId, missionId, workflowId, domain, status, eventCount, events)
  — runId/missionId/workflowId/domain/status: requiredText；eventCount: nonNegativeInt；events: 必有列表
TraceEventQuery(eventId, runId, stepId, agentName, eventType, observation, payload, durationMs, createdAt)
  — eventId/eventType/createdAt: required；runId/stepId/agentName/observation: text 可空；
    durationMs: nonNegativeLong；payload: TracePayloadQuery
TracePayloadQuery(...已知读取键 typed 字段..., extras: List<TracePayloadEntry>)
TracePayloadEntry(key: String, value: String, kind: "string"|"number"|"boolean"|"list"|"object"|"null")
```

- 已知键按**实际读取函数**定类型（observation.ts + runtimePresentation.ts 逐键核对）：字符串键（status/kind/stage/category/message/summary/summary 类/tool/name/provider/model/finishReason/commitId/outputRef/artifactRef/channel/checkpointId/decision/subjectType/operationId/reviewer/comment/reason/errorCode/code/patchId/…）、数值键（latencyMs/durationMs/tokens/tokensDelivered/ttftMs/taskCount/nodeCount/edgeCount/…scalarCount 读取 → Integer）、布尔键（planningProgress/stochasticFallback/outputExhausted/written/streaming）、列表键（stepIds/failedResources/retryStepIds/fields/consumedFields/hitRefs/notes/selectionReasons/…）、嵌套对象键（usage/capability/outputPolicy/memoryAccess 细目/topologyAudit/pendingMemory）。
- **类型不符的已知键不 502，降级进 extras**（理由：payload 是开放审计载荷，单键类型漂移不应毁掉整个 Trace 的可用性；与 G1"必有对象缺失→502"的语义区分点，见待裁决 #2）。
- extras 上限 24 项（对齐前端 MAX_OBJECT_FIELDS），值经 Java 侧安全序列化为展示字符串（有限深/有限长/循环防护），`kind` 保留前端 `code: typeof !== 'string'` 所需的区分。
- 前端适配（最小）：`runtimePresentation.ts` generic 分支把 `extras` 展开为详情行（一处小改 + spec 更新）；其余消费者零改动——全部已核实的读取键都在 typed 字段或 extras 中可达。
- 守卫兼容：无 Map/JsonNode/Object 字段；不触碰 Role JSON 例外。

### 方案 B（对照）：按 eventType 家族的全有限 union DTO

保真最高，但 (a) generic 任意键展示仍无处安放；(b) `usage` 子对象的 `input_tokens` 可能是 `"[redacted]"` 字符串，typed TokenUsage 会被迫 502 或自身退化为动态结构；(c) 26 家族 × 未知事件兜底，DTO 面积大、前端需按 union 重写全部读取。实际会退化为方案 A 加一层无收益的包装。**不建议。**

### 通用规则（两方案共用）

- 不重排 events（生产端已按 createdAt,eventId 排序）；无分页（无 nextCursor）；`view` 原样转发。
- workspace 视图下 `eventCount > events.size()` 合法，禁止断言相等。
- 复用 QueryWire 既有 helper；数值走 BigDecimal 精确转换（E2 定案）；NON_NULL 归一（全部读取端 `?.`/`||`/`??`/`== null` 已核实）。

## 6. 未知事件与结构损坏策略

| 输入 | 处理 |
| --- | --- |
| 信封缺键/类型错（runId/missionId/workflowId/domain/status/eventCount/events） | 502 AGENTOS_CONTRACT_INVALID（信封是必有结构） |
| 事件行骨架必需（eventId/eventType/createdAt）缺失/类型错 | 502（结构损坏，与信封同级；当前 pydantic 合同使其实际不可达） |

| payload 未知键 / 已知键类型漂移（含 [redacted] 替换） | 降级进 extras，不 502 |
