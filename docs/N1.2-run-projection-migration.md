# N1.2 Run / Graph 查询边界

本批将已有 Run、Graph、execution-tree 和 review history 查询结果映射为显式 DTO。Mapper 仅读取 Client 返回值；没有新增 Service、数据库查询、Runtime 调用或状态写入。命令接口及其既有响应不在本批迁移范围。

## 接口

| Endpoint（前缀 `/api/agentos/v2`） | Owner | Public response |
|---|---|---|
| GET `/runs` | AgentOsRunController | RunPageQuery |
| GET `/runs/{runId}` | AgentOsRunController | RunQuery |
| GET `/runs/{runId}/graph` | AgentOsObservationController | GraphQuery |
| GET `/runs/{runId}/execution-tree` | AgentOsObservationController | RunExecutionTreeQuery |
| GET `/runs/{runId}/reviews` | AgentOsReviewController | ReviewHistoryQuery |

查询参数、Client 调用路径、权限上下文和上游 HTTP 状态沿用现有实现。统一错误仍由 AgentOsControllerSupport 和既有异常处理器处理；合法数据使用白名单映射，类型不符合约定时返回既有 `AGENTOS_CONTRACT_INVALID` 格式，避免回退透传。

## 字段兼容表

| old field | new field | frontend consumer |
|---|---|---|
| Run 的身份、状态、步骤、时间、进度、outputRef/runtimeRevision | 同名公共字段 | WorkflowRunPanel、历史列表、Workbench |
| executionState.reviewPayload | review（审核对象、原因、迭代、票数摘要） | WorkflowReviewPanel；审核命令目标与状态约束保留 |
| executionState.outputRefs/outputSummaries | outputs[]（stepId/outputRef/summary） | createAcgApi 产物读取 |
| executionState.graphVersion | graphVersion | GraphEditor、Run summary、历史图版本展示 |
| executionState 中规划复现参数 | planningDiversity/planningSeed/plannerAlgorithmVersion/planningCandidateCount/selectedPlanningVariantId | 规划复现展示；恢复草稿仍读取既有 history-config |
| executionState 中父子 Run 字段、operational.lineage | lineage | AcgExecutionContractBar、观察适配器 |
| execution-tree.blueprint.graph | graph | 图展示；仅公共 node/edge/display 字段，wrapper graphId/version/missionId 显式映射 |
| graph node/edge.metadata | display | GraphEditor / 图展示消费者；白名单包含语义任务、角色、能力展示和排序信息 |
| task.constraints | constraintCount | 当前消费者仅显示任务事实；不输出内部约束模型 |
| executionBinding | resourceUse（resourceId/agentId/modelId/acgNodeId/deploymentTier） | NodeResourceInspector、ResourceSidebar、resourceObservation |
| operational.nodeExecutions | lifecycles[]（stepId/attemptId/phase/failureCode/sequence） | AcgTopologyGraph、AcgOperationalInspector、运行观察适配器 |
| executionInstanceId / loopPath | 删除；仅用于 Mapper 计算公共 sequence | 保持原 UI 的 attempt、loop、instance 排序与最新生命周期选择，不暴露控制标识 |
| bindingId/bindingHistory/placementPolicy/scoring | 删除 | 不再显示内部资源分配决定；保留已观察到的资源身份 |
| checkpointId / scheduler / controlFrames / compiled package / graphPatchRefs | 删除 | UI 移除内部 ID、包校验和及 raw control 信息，保留审核入口、产物与生命周期展示 |
| review operationId / traceEventId | 删除 | 审核历史保留 reviewId/runId/stepId/decision/reviewer/comment/createdAt |

GraphProjection 为公共前端类型，独立于内部 ACGBlueprint。查询 DTO 不继承 Runtime/Entity 类型；Role 专用配置树不复用于 Run 或 Graph。

## 测试与边界

RunProjectionBoundaryTest 验证审核目标、输出引用、lineage、Graph wrapper 身份、资源观察和生命周期排序；递归注入敏感哨兵，确认 binding/package/checkpoint/scheduler 等不序列化，映射不修改原列表。

QueryProjectionArchitectureTest 统一扫描所有 projection DTO 与 Mapper，保留身份 Controller 的 Entity 禁止规则。前端测试改用公共契约，保留审核命令、产物读取、未知资源能力、Run 切换竞态与 provenance 指标回归。

本批未修改 Python Runtime、domain model、ACG Kernel、数据库、依赖或命令行为。Workspace、Trace、Memory、Provenance、Resource catalog、history-config、动态 `/ai/**` 与 SSE 的输出迁移仍应按后续批次完成，不能据此宣称全仓 Query 边界已隔离。实际浏览器与部署环境验收尚未执行。

已通过后端干净构建全量 340 项测试与生产打包、前端全量 552 项测试、最后一轮相关 51 项定向回归，以及最终 Web / Desktop 类型检查和生产构建。重复测试守卫的清理说明见 [N1.2-test-maintenance.md](N1.2-test-maintenance.md)。
