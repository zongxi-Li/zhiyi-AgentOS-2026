# 知弈 AgentOS 测试与冻结门禁规范

开发期采用分级测试：L0 验证单点改动，L1 验证任务块和关键失败反例，L2 使用五分钟内的冻结门禁，L3 才执行完整 pytest、长时压力和大规模性能验证。除用户明确要求完整验收或正式发布验收外，不自动执行全量 pytest，也不重复执行“定向、扩大、全量”三轮回归。

L2 从仓库根目录运行：

```powershell
python scripts/freeze_gate.py
```

脚本比较 `apps/agentOS/src` 与 `apps/agentOS/tests` 的当前 SHA-256 清单和上一阶段基线，根据变更模块选择对应测试。源模块必须在 `SOURCE_TEST_RULES` 中映射到合同测试；新增关键反例使用 `pytest.mark.freeze_gate`。脚本在测试前收集实际 node ID，去重后只运行一次；已记录的单项耗时用于预算预检，未知耗时保持未知，并由 300 秒硬截止保护。

超时或已知耗时超过剩余预算时，结果标为未完成，不把未执行用例计作通过。完整日志、机器可读结果和逐项耗时保存在被忽略的 `tmp/freeze_gate/`。性能基准标注 `slow_benchmark`，真实多进程竞争标注 `slow_multiprocess`，长时故障注入标注 `slow_fault_injection`。L2 默认排除这些慢测，但显式标记为 `freeze_gate` 的关键安全反例仍会执行。完整 pytest 不受这些 marker 影响，会继续收集并运行全部测试。
