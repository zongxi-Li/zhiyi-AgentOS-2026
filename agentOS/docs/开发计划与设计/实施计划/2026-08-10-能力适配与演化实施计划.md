# 能力适配与演化实施计划

> 创建（Git）：2026-08-11T23:24:00+08:00，WKN
> 最近一次 Git 修改：2026-08-11T23:24:00+08:00，WKN

> **面向执行智能体：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，逐项执行本计划；步骤通过复选框（`- [ ]`）跟踪。

**目标：** 为外部能力适配、图演化和技能自演化建立可导入的合同与服务门面，并有意暂缓实现运行时算法。

**架构：** 外部适配器仅依赖 `contracts.capability`；演化组件仅依赖 `contracts.evolution`。服务门面用于生成或校验未来的演化提案，绝不能直接修改正在运行的图或技能注册表。

**技术栈：** Python 3, Pydantic v2, `typing.Protocol`, pytest.
