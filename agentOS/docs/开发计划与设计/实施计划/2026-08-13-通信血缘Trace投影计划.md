> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 将低熵通信的生产、消费和交互血缘投影为持久 Trace，供审计、记忆策略和后续轨迹演化消费。

**架构：** `CommunicatorService` 继续在 run 内维护 `ProvenanceLedger`；节点运行器从账本取得新事件并返回安全投影；执行图将投影附带在 `node_completed` 事件；Runtime 映射为既有 `DATA_PRODUCED` 与 `DATA_CONSUMED` Trace。投影只包含字段名、校验和、事件 ID、引用、token 统计和节省率，绝不包含 slot 正文、ContextPack 正文或模型输出。

**技术栈：** Python 3.10、Pydantic 2、pytest、现有 CommunicatorService / TraceStore / ACG Runtime。
