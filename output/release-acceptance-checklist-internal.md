## 1. 前置要求

| 项 | 要求 |
| :-- | :-- |
| 系统 | Windows 11（x64） |
| 权限 | **普通用户**即可，不需要管理员、不装服务、不改 PATH、不写注册表 |
| 路径 | **必须是纯英文路径**（可含空格，如 `D:\ZhiyiAgentOS 1.0`）。中文路径会让 PostgreSQL 无法初始化 |
| 磁盘 | 解压后约 1.4 GB；运行时数据随使用增长（首启约 200 MB） |
| 网络 | 配置好 API Key 后需要能访问对应模型服务；本地服务全程 loopback |

---

## 2. 首次使用（5 步）

1. 解压到纯英文目录（**不要**解压到 `C:\Program Files` 之类需要写权限的位置）。
2. 双击 `start.cmd`。首次会自动：
   - 创建数据目录 `data-home\`（PostgreSQL 集群、SQLite、workspace、日志）
   - 自动注册一个本地账号并登录（**不需要也不能手动登录**）
   - 拉起 PostgreSQL / Memurai / Hands / AI 服务 / Java 后端 / 终端服务
   - 打开桌面窗口
3. 进 **设置 → 模型供应商**，填写你的 API Key → 测试连通 → 保存并**激活**。
4. 回到解压目录，双击 `restart.cmd`。**不重启不会对规划与执行链路生效。**
5. 试一句对话；再到「新建任务」跑一个 Mission。

> 首次启动耗时约 40–60 秒（要初始化数据库）；后续启动约 15–25 秒。

## 4. 运维速查

| 操作 | 命令 | 说明 |
| :-- | :-- | :-- |
| 启动 / 确保在跑 | `start.cmd` | 服务已在跑时只重开窗口 |
| 停止 | `stop.cmd` | 优雅停止，保留数据 |
| 重启 | `restart.cmd` | **改完 API Key 必须执行** |
| 看状态 | `status.cmd` | 输出 JSON：进程、端口、三项就绪检查 |
| 日志 | `data-home\logs\<会话时间>\` | `ai.log` / `java.log` / `host.log` / `desktop.log` / `postgres.log` / `redis.log` |
| 桌面壳日志 | `data-home\electron\logs\main.log` | 页面加载、IPC 拒绝、崩溃 |
| 彻底卸载 | 删除整个解压目录 | 数据在 `data-home\`，一并删除 |

### 默认端口（可整体偏移）

| 服务 | 默认 | 说明 |
| :-- | --: | :-- |
| PostgreSQL | 15432 | 独立集群，仅 loopback |
| Memurai | 16379 | Redis 兼容层，仅 loopback |
| AI 服务 | 18761 | FastAPI |
| Hands | 18765 | 执行资源服务 |
| Java 后端 | 18080 | 桌面壳直连的 API |
| 终端服务 | 18766 | PTY 服务 |

端口被占用时启动器会**整体挑一组空闲端口**并写入 `data-home\environment.json`；不会杀掉占用进程。

## 5. 常见问题

| 现象 | 原因 / 处理 |
| :-- | :-- |
| 启动报"程序目录包含中文" | 解压到纯英文目录（PG 不支持非 ASCII 路径） |
| 启动报"端口被占用（PID/PID 名称）" | 关掉占用程序后重试；或删掉 `data-home` 重新首启（会重挑端口） |
| 双击后窗口一闪就没了 | 看 `data-home\electron\logs\main.log`；常见是同一 `data-home` 已有实例在跑 |
| 对话报"AI服务当前不可用" | Key 无效或未激活供应商；去设置页测试连通性后 `restart.cmd` |
| 设置页左侧找不到"模型与 API" | **第七轮已修复**：侧栏「工作区」组现有「模型与 API」入口（包内渲染层热修，CDP 实测通过）。持旧版包时需发布者深链 `#/settings?tab=model` 切页 |
| 进了"模型与 API"页但找不到"服务端供应商" | 先点第一张「**系统默认**」卡片它才会出现（选中具体供应商时隐藏）；填 Key 走「新增供应商」并**用同名覆盖**（如名称填 deepseek），保存后点卡片确认「当前」，再 `restart.cmd` |
| 建任务立刻失败"ACG 工作流执行失败" | 十有八九是没配 Key 或没重启；先确认设置页有**已激活**的供应商，再 `restart.cmd` |
| 任务停在"正在规划"很久 | 正常，真实模型规划可能 1–2 分钟；不要重复点 |
| 隔夜后所有操作报"登录状态已过期" | 会自动重登；若停在登录页，`restart.cmd` 后重新打开 |

## 6. 已知限制（内部版）

1. **Memurai 为 Developer 版**：仅限开发测试用途，连续运行最长 10 天；不得对外分发。
2. **未签名**：Windows 可能提示"未知发布者"，选择"仍要运行"。
3. **单用户单实例**：一个 `data-home` 同时只允许一个实例；多账户/多租户不在本版范围。
4. **登录体系未移除但被隐藏**：首启自动建号登录，界面不出现登录页；代码保留以便将来恢复账号体系。
5. **模型配置需重启生效**：Settings 保存后必须 `restart.cmd`。
6. **架构门禁仍有一项红灯**（`test_electron_host_does_not_embed_execution_authority`），属仓库既有问题，不影响运行。
