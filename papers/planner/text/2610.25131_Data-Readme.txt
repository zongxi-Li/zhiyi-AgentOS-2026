                                                                         6    Related work
                                                                         Dataset annotation using LLMs. In addition to earlier work that
                                                                         uses traditional methods to expand the semantics of tables and
                                                                         columns [17, 26, 42, 48, 52], recent work such as AutoDDG [53]
                                                                         and TACO [11] use LLMs to generate dataset and column descrip-
                                                                         tions based on table content. Data.Readme addresses a different
                                                                         limitation: independently annotating each table does not explain
                                                                         relationships between tables. We therefore augment per-table de-
                                                                         scriptions with structured, lake-wide relationships and develop
                                                                         tools that let agents retrieve and traverse them, which are shown
                                                                         to improves the quality and efficiency of downstream data tasks.
                                                                         Join discovery and search. There is a large literature on join
                                                                         discovery that aims to identify all joins from a set of tables, where
                                                                         most prior work focus on join discovery in smaller-scale, database

                                                                         alone may produce spurious connections.
