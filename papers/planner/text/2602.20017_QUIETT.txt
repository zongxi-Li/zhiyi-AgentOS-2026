Figure 2: Q U I E TT framework for robust table reasoning. Stage 1: Issue Probing. Synthetic queries are generated from the
raw table to expose structural issues such as inconsistent formats, implicit relations, missing derived fields, and undecomposed
attributes. Stage 2: Transformation. Detected issues guide a transformation plan that applies normalization, parsing, restructur-
ing, and derived column creation, executed via code to materialize a canonical, SQL-ready table. Stage 3: QA. The transformed
table is reused across all downstream queries, enabling accurate and consistent reasoning without modifying the underlying
model or prompting strategy.
