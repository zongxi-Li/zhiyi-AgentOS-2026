Analysis. As shown in Table 6, EviDARL re-
duces end-to-end latency from 12.67 s to 5.67 s
compared with Table-R1, corresponding to a 55.2%
reduction. Although EviDARL invokes the model
multiple times and has a higher time to first token
(TTFT), measured from when Agent 1 receives the
input to when Agent 2 generates its first token, its
agents operate without a thinking mode, thereby
avoiding test-time scaling (TTS) and substantially
reducing computational overhead while potentially
achieving higher accuracy. This is the primary rea-
son its overall latency remains lower than that of
Table-R1. The shorter input contexts provided by
compact table representations offer an additional
efficiency gain. Moreover, EviDARL generates
substantially fewer tokens (523 vs. 1,821), while
code execution contributes only 0.014 s, demon-
strating that its dual-agent workflow maintains low
inference cost despite the additional stage depen-
dency.
