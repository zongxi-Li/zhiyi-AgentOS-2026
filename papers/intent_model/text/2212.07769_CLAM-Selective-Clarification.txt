data set.
As done in Xu et al. (2019), the description of the two entities is provided to the question answering model together with the

C. CLAM Algorithm
We tune the decision threshold τ used to detect ambiguity in CLAM (see Algorithm 1) to maximize the QA accuracy on a
holdout data set of ambiguous and unambiguous questions and use τ = −0.3 in the remaining experiments.

Algorithm 1 Selective clarification of imprecise questions
Require: A language model M, a question Q, a user U, ambiguity classifier f .
  A ← M(Q) {Ask language model to answer question Q}
  ambiguous ← f (Q, M) {Classify ambiguity, e.g., with few-shot prompted LLM}
  if ambiguous then
     Q0 ← concat(Q, “To answer this question, I have to ask the following clarifying question”)
     Q̂ ← M(Q0 ) {Ask a clarifying question Q̂}
     Â ← U(concat(Q, Q̂)) {Get clarification from user or oracle}
     A ← M(concat(Q, Q̂, Â)) {Return answer given entire dialogue}
  end if
  return A
