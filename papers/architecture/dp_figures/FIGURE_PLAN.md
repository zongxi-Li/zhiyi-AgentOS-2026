# 差分隐私论文图组：设计约束

日期：2026-11-19。范围仅为已讨论的差分隐私架构；不扩展到另外两个主题。图展示目标设计，不表示仓库已实现 DP 或已经完成形式化证明。

| 图 | 主题与唯一解释任务 | 用途 |
|---|---|---|
| 1 | 信任边界与模块架构：私有激活只有经过本地发布门才能到达云端 | 主文候选 |
| 2 | 成功发布的数据流：预算预留、唯一载荷和发送标记必须先于网络输出 | 主文候选 |
| 3 | 持久发布状态机：未知出站和不可恢复故障不释放已计费用 | 补充材料候选 |
| 4 | Gaussian 与组合会计：先计算前瞻费用，通过门槛后原子加入账户 | 主文候选 |
| 5 | 丢失回执的恢复时序：查询受串行保护的远端状态，避免重采样或重复推进 KV | 补充材料候选 |
| 6 | 可观测协议闭包：数值、元数据和交互行为都要落在声明范围内 | 补充材料候选 |

每张图制作英文论文版和中文审阅版。主文/补充材料只是建议，没有具体会议模板时不声称符合某个会议的全部投稿规定。

固定视觉语义：蓝色表示本地计算或私有输入，青色表示隐私发布机制，紫色表示持久状态与会计，灰色表示云端/公开配置，橙色表示拒绝或不可恢复故障。白底、无阴影、Arial/微软雅黑、有限字号、正交连线。实线为数据或正常状态推进，虚线为控制/回执/恢复；所有故障均同时用文字标识，颜色不是唯一编码。

导出目标：原生多页 draw.io XML、逐图 SVG/PDF 和高分辨率 PNG。SVG 不使用 HTML foreignObject，以便论文工具链使用；PDF检查字体和文本。180 mm 双栏宽度下，正文标签目标不低于约 8 pt。具体会议最终宽度须在排版时再核对。

关键逻辑：

1. 公开固定协议下的 prompt replacement；一次完整向量裁剪，Δ₂≤2C。
2. 固定参数/最大次数的 Gaussian 原型；条件逐步 RDP 上界和相同保护范围才能组合。
3. 预算账户的 charged 向量包含所有预留，ACK 不再次计费；恢复不退款。
4. RESERVED→PREPARED→MAYBE_SENT→ACKED；进入 MAYBE_SENT 后才可网络发送。
5. 同 releaseId 永远只绑定一个随机载荷；缺少载荷不能重新采样冒充旧发布。
6. 云端去重与 KV/采样/回执逻辑提交独立于隐私账本；远端不确定则停止或查询。
7. “未提交”必须来自受会话串行控制的权威状态，不等于普通 lookup 返回空。
8. 私有长度、offset、mask、停止、时序和异常行为不能绕过声明；保护范围外项目必须明确公开或排除。
9. 模型/图/技能回滚不回滚预算；参考图不是生产能力或安全保证。
