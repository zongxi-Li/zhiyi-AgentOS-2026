## LangGraph 执行基础层

AgentOS 采用并改造了 LangGraph **1.2.10** 的部分执行概念与实现结构，上游提交为
`d56666f7fbf0d380ad84cdf0cbe5aa48ab0cc086`.

适配后的文件会在文件头标明来源模块及修改内容：

- `src/components/executor/graph.py`：采用 StateGraph/Pregel 就绪集语义，收束为
  AgentOS 的引用状态与流事件。
- `src/components/executor/compiler.py`：采用 StateGraph 编译语义，改为处理 AgentOS ACG
  Blueprint 并执行通信治理。
- `src/components/recovery/checkpoint.py`：采用 SQLite 检查点语义，改为将 AgentOS
  运行引用状态以 `runId` 作为 SQLite 线程 ID 存储。
- `src/components/executor/node_runner.py`：采用节点执行语义，改为使用 AgentOS
  ContextPack、MemoryService、适配器及 Trace 引用。
- `src/components/auditor/governance/trace.py`：采用 Pregel 事件投影，仅输出既有的
  AgentOS `TraceEvent` 值。
