# AgentOS 当前实现梳理

核对日期：2026-11-16。完整目录和部件职责见 [AgentOS README](../README.md)，全系统调用图见[当前架构图](../../../docs/架构设计/kinlin-agentos-current-architecture.md)。历史实施计划描述各阶段快照；本文按当前源码说明归属。

## 入口与执行链

```text
apps/agent/app/main.py
  → app/execution/wiring.py（产品装配）
  → runtime/workflow_runtime.py::ExecutionRuntime（公开门面）
  → runtime/orchestration/（准备、规划、执行、审核、恢复与提交协调）
  → planner → 编译包 → executor/ACGExecutionGraph
  → scheduler 就绪选择 → resource 绑定与租约 → ACGNodeRunner
  → communicator / memory / auditor / recovery 及各自存储
```

`runtime/composition/` 提供内核装配、配置和注册；产品应用通过明确注入接入。`workflow_runtime.py` 不再承载完整用例实现，稳定公开类型继承 `orchestration/workflow.py` 的应用实现。执行图仍由 AgentOS 自身推进，使用内部 StateGraph/Pregel 机制。

## 源码归属

| 路径 | 当前职责 |
| --- | --- |
| `src/contracts/` | 跨部件、跨进程的数据与能力协议；ACG 合同在 `contracts/acg/`。 |
| `src/domain/` | 共享身份实体、关系、不变量、生命周期及纯图规则；`repository/` 只定义接口与错误。 |
| `src/components/` | 固定 13 个业务部件。mission/planner/resource/scheduler/executor/communicator/memory/auditor/recovery 为 core，attachments/environment 为 basic，evolution/safe 为 great。 |
| `src/runtime/composition/` | 配置、依赖装配、注册与生命周期。 |
| `src/runtime/orchestration/` | 跨部件用例、版本校验与提交协调；包含写入身份状态的投影和 reconciliation 协调。 |
| `src/runtime/projections/` | 工程、执行、查询的只读聚合；真实工作区与内容归 environment。 |
| `src/runtime/events/` | 进度分发、订阅和通知；不替代 communicator 的业务消息投递。 |
| `src/runtime/compatibility/` | 技术兼容导出；运行锁只有 `support/run_locks.py` 一份实现。 |
| `src/adapters/{model,agent,tool,retrieval,transport}/` | 模型、外部 Agent、工具、检索与通用传输接入。原 `service/agents/` 注册与协议实现已进入 adapters，实例池和供给进入 resource/agents。 |
| `src/storage/` | 共享 Identity / New ACG 数据库实现，路径不再包含 `v2/`。 |
| `src/support/stores/` | 历史 WorkflowStore 及规划/执行提交存储；与 storage 的 schema 隔离。 |
| `src/support/acg/` | 兼容转发；合同、图校验和就绪算法各有唯一实现，不在此复制。 |
| `src/support/{packs,skills}/` | Pack 发现、注册以及技能基础设施。 |
| `src/tools/` | ACG 只读导出、序列化与绘图。 |

共享 DTO 与领域实体有不同语义，不因名称相近而合并。存储连接、业务存储策略及数据库 schema 也按各自边界维护。

## 关键迁移与能力边界

- 纯审核规则归 auditor；初始规划编译、不可变 ACG 包编译与语义补丁归 planner；规划输入和身份生命周期归 mission；模型配额归 resource；共享状态映射归 domain。executor/compiler 只适配执行图，复用 planner/package_compiler 的唯一包编译规则。
- scheduler 提供统一依赖判定与就绪选择，executor 消费该门面。资源评分、绑定与租约仍由 resource 负责，当前没有统一求解所有容量、权限和预算约束的最大子图优化器。
- 原 marketplace 归 `components/resource/catalog/`，不再作为额外顶层部件。
- content、Hands、compact 分别位于 `components/environment/` 下；Hands 和 compact 保持独立 TypeScript 项目及进程边界。
- safe 整体位于 `components/safe/`。模型分区校验归 `safe/integration/model_partition.py`，共享合同仍在 `contracts/model_partition.py`；分区服务执行仍明确拒绝。safe 的真实拆分推理与认证 HTTPS 装配见[模块状态](../src/components/safe/README.md)，DP 发布和持久隐私预算仍未接通。
- 摘要去重保留两种原有语义：`contracts/stable_digest.py` 计算完整 JSON 字段摘要，`stable_checksum` 保留省略默认值的规范化协议。

## 测试与资料

| 路径 | 用途 |
| --- | --- |
| 仓库根 `TEST/tests/` | AgentOS Python 测试；仓库根使用 `python -m pytest -c apps/agentOS/pytest.ini TEST/tests`，AgentOS 目录使用 `python -m pytest`。importlib 收集避免同名模块冲突。 |
| 仓库根 `evals/` | 评估和实验；模型评估脚本可能访问真实提供商，按对应说明独立运行。 |
| `src/components/environment/{hands,compact}/` | 独立 TypeScript typecheck/test；按各自 package.json 使用 Node >=24.9。 |
| `apps/agentOS/docs/`、仓库根 `docs/` | 设计、实施与历史验证记录；本轮验证和已知限制见[迁移记录](../../../docs/superpowers/plans/2026-11-15-agentos-architecture-convergence.md)。 |

运行时公开入口、唯一执行图、身份写入协调和只读查询投影承担不同职责。Identity 生命周期服务归 mission，写入协调归 orchestration，查询归 projections；它们不形成第二个执行器。
