# AgentOS 统一 Python 环境

从 2026-11-16 起，唯一安装入口是应用根目录的 `requirements.txt`。它覆盖
AgentOS 基础运行、本地文档工具、Safe 拆分推理、HTTP/TLS、实验绘图和回归测试。
原来的七份工具/Safe 输入和锁文件不再作为安装入口。

## 安装与验证

本轮参考环境为 **Windows x64、CPython 3.10、Torch CPU**。从仓库根目录执行：

```powershell
py -3.10 -m venv apps/agentOS/.venv
apps/agentOS/.venv/Scripts/python.exe -m pip install --require-hashes -r apps/agentOS/requirements.txt
apps/agentOS/.venv/Scripts/python.exe -m pip check
apps/agentOS/.venv/Scripts/python.exe -m pytest -c apps/agentOS/pytest.ini TEST/tests/safe
apps/agentOS/.venv/Scripts/python.exe evals/safe/test/test_safe_data_flow.py
```

不需要激活环境，也不再分开安装 HTTP、绘图或本地工具依赖。安装时需能访问
PyPI 和官方 Torch CPU 源；模型权重不包含在依赖中，仍须事先准备批准的离线制品。
TypeScript 部件继续使用各自的 Node 配置；Agent 应用自身的其他 Python 依赖
仍属于 `apps/agent`，本次合并范围为 AgentOS 的这八份配置。

## 版本与离线复现

`requirements.txt` 同时承担依赖清单和平台锁的职责：所有直接、传递依赖均使用
`==` 和实际 wheel 的 SHA256。原有模型/HTTP/绘图固定版本保持不变；基础运行和
测试中的范围依赖在统一解析后精确固定。文件按用途注释分组，没有 `-r` 嵌套入口。

同一平台可先准备 wheel 目录，再安装到另一全新环境：

```powershell
apps/agentOS/.venv/Scripts/python.exe -m pip download --only-binary=:all: --require-hashes -r apps/agentOS/requirements.txt -d data/agentos-wheels
apps/agentOS/.venv/Scripts/python.exe -m pip install --no-index --find-links data/agentos-wheels --require-hashes -r apps/agentOS/requirements.txt
```

不要在这个锁上直接放宽单个版本或拼入 `pip freeze`。更新时应重新解析完整依赖集合，
从下载的 wheel 元数据读取版本并计算哈希，用全新环境执行安装、`pip check` 和相关回归。
Linux、其他 Python 版本和 CUDA 需要重新生成对应 wheel 哈希并验收；当前文件未覆盖这些平台。

## 历史实验

旧的三个 Safe 锁按原始字节归档在
[历史实验依赖证据](../../../docs/superpowers/reports/safe/dependencies/2026-11-15/README.md)。
历史实验中的旧文件路径与哈希保留，便于复核；日常安装以新的统一入口为准。
新的 HTTPS 实验报告记录 `dependency_file` 和 `dependencies_sha256`，指向统一配置；
旧报告的 `http_lock_sha256` 保持原意，绘图脚本继续兼容已有报告。
