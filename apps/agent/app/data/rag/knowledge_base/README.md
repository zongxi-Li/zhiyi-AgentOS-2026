# 知识库文档说明

## 目录结构

本目录包含按职业/角色分类的知识库文档。每个文档对应一个特定的职业角色。

## 文档命名规范

文档命名格式：`角色名-知识库.md`

例如：
- `律师-法律知识库.md` - 律师角色的法律知识
- `教师-教育知识库.md` - 教师角色的教育知识
- `程序员-技术知识库.md` - 程序员角色的技术知识
- `作家-文学知识库.md` - 作家角色的文学知识

## 角色ID映射

系统使用以下角色ID映射：

- `律师` -> `lawyer`
- `教师` -> `teacher`
- `程序员` -> `programmer`
- `作家` -> `writer`

## 知识库分类机制

1. **文档上传时分类**：上传文档时，系统会根据当前选择的角色ID自动将文档分类到对应的知识库。

2. **查询时过滤**：进行RAG查询时，系统会自动过滤，只从当前角色的知识库中检索相关内容。

3. **知识图谱构建**：知识图谱也会按角色分类构建，确保不同角色的知识图谱相互独立。

## 使用方法

### 初始化知识库

运行初始化脚本，将示例文档导入到知识库：

```bash
cd agent
python app/scripts/init_knowledge_base.py
```

### 添加新文档

1. 在知识库页面选择对应的角色
2. 点击"上传"按钮
3. 选择或拖拽文档文件
4. 文档会自动分类到当前角色的知识库

### 查询知识库

1. 在知识库页面选择对应的角色
2. 在查询框中输入问题
3. 系统会从该角色的知识库中检索相关内容并生成回答

## 文档格式要求

- 支持格式：`.md`, `.txt`, `.pdf`, `.doc`, `.docx`
- 推荐使用Markdown格式，便于知识图谱构建
- 文档内容应结构化，包含清晰的标题和段落

## 知识图谱可视化

在知识库页面的"知识图谱"标签页中，可以查看当前角色知识库的可视化图谱，包括：
- 实体节点
- 关系边
- 统计信息
