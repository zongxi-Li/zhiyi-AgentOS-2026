# 律师职业知识库

## 合同法基础知识

### 合同的定义和要素
合同是当事人之间设立、变更、终止民事权利义务关系的协议。合同应当具备以下要素：
1. 当事人：具有完全民事行为能力的自然人、法人或其他组织
2. 意思表示：双方真实意思表示一致
3. 标的：合同指向的对象，可以是物、行为或智力成果
4. 内容：合同的具体条款，包括权利义务关系

### 合同的成立和生效
- 合同成立：当事人就合同主要条款达成一致
- 合同生效：合同成立后，符合法律规定的生效要件
- 生效要件：当事人具有相应民事行为能力、意思表示真实、不违反法律强制性规定

### 合同违约责任
当事人一方不履行合同义务或履行不符合约定的，应当承担违约责任：
- 继续履行
- 采取补救措施
- 赔偿损失
- 支付违约金

## 劳动法核心内容

### 劳动合同
劳动合同是劳动者与用人单位确立劳动关系、明确双方权利义务的协议。

### 工作时间
- 标准工作时间：每日8小时，每周40小时
- 延长工作时间：每日不超过3小时，每月不超过36小时
- 休息日：每周至少休息1日

### 工资支付
用人单位应当按照劳动合同约定和国家规定，及时足额支付劳动报酬。

## 知识产权法

### 著作权
著作权是指作者对其创作的文学、艺术和科学作品享有的专有权利。

### 专利权
专利权是指发明创造人对其发明创造享有的专有权利。

### 商标权
商标权是指商标注册人对其注册商标享有的专有权利。

## 常见法律问题解答

### 合同纠纷处理
1. 协商解决：双方友好协商
2. 调解：通过第三方调解机构
3. 仲裁：提交仲裁机构裁决
4. 诉讼：向人民法院提起诉讼

### 劳动争议处理
1. 协商：用人单位与劳动者协商
2. 调解：向劳动争议调解组织申请调解
3. 仲裁：向劳动争议仲裁委员会申请仲裁
4. 诉讼：对仲裁裁决不服的，可以向人民法院提起诉讼

## 角色协作与办案流程

### 律师团队协作案例
张明律师属于星河律师事务所，负责劳动争议与合同审查。
李敏律师属于星河律师事务所，参与企业合规项目。
张明律师与李敏律师合作处理青禾科技公司劳动合同纠纷案件。
青禾科技公司位于杭州，公司人事部门负责劳动合同管理。
劳动合同纠纷案件包含证据整理、法条检索、仲裁申请和庭审提纲。

### 法律咨询标准流程
1. 接收咨询：明确争议类型、合同状态、证据情况。
2. 识别法律关系：区分劳动争议、合同纠纷、侵权责任或知识产权争议。
3. 检索规则：优先查找法条，再补充案例和程序性规则。
4. 风险提示：明确时效、举证责任、执行难度和和解空间。
5. 交付结论：给出行动清单、所需材料和下一步程序安排。

### 常见角色能力标签
- 劳动争议律师：擅长未签合同、工资支付、违法解除和工伤赔偿。
- 合同律师：擅长条款审查、违约责任认定和履约风险控制。
- 合规律师：擅长制度审查、业务流程合规和证据留存方案。
- 知识产权律师：擅长著作权、商标权和商业秘密保护。
