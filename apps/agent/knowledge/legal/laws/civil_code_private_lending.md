# 民法典民间借贷演示资料

> 演示资料：本文件不是完整法规库，不替代正式法律法规文本。后续需要替换为经过校验的正式法律知识库。

## 借款合同基础审查

借款类合同宜关注借款金额、用途、期限、利息、还款方式、提前还款、逾期后果、担保措施和争议解决。金额、期限或利息表达不清时，后续履行和争议处理成本会升高。

## 资金交付与还款证据

借款审查中应关注资金交付凭证、账户信息、还款流水、收款确认和对账机制。仅有口头确认或单方记录时，证明链条可能不足。

## 担保与风险隔离

涉及保证、抵押、质押或第三方承诺时，应分别明确担保范围、担保期间、实现方式和资料留存要求。演示资料不提供具体条文编号，正式依据需由后续法律知识库校验。
