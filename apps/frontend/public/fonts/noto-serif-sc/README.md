# Noto Serif SC

Locally hosted WOFF2 unicode subsets for the existing 500, 600 and 700 font weights.
Downloaded from Google Fonts on 2026-09-17. The CSS retains the provider's unicode
ranges and `font-display: swap`; only font URLs are replaced with local paths.
Browsers fetch the subsets needed by the text rather than the complete font.

Source stylesheet: https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@500;600;700&display=swap
