# 知弈 AgentOS Frontend

Vue 3前端应用

## 技术栈

- Vue 3
- TypeScript
- Vite
- Element Plus
- Pinia
- Three.js (数字人渲染)

## 安装依赖

```bash
npm install
```

## 开发

```bash
npm run dev
```

## 构建

```bash
npm run build
```

## 项目结构

```
frontend/
├── src/
│   ├── components/  # 组件
│   ├── views/       # 页面
│   ├── stores/      # 状态管理
│   ├── services/    # API服务
│   └── router/      # 路由
```
