# Prompt Runtime Provider Matrix

Production model registration is configuration-driven through `ApplicationSetup` and one `OpenAICompatibleRuntime`. The registry accepts provider identifiers from `AGENTOS_MODELS`; therefore the code does not claim native support for every named vendor. The matrix distinguishes the tested generic wire contract from explicit provider branches.

| Provider family | Endpoint mode | System role | Multiple system behavior | Structured output | Streaming | Schema mode | Prompt ordering | Known limitations | Test status |
|---|---|---|---|---|---|---|---|---|---|
| Generic OpenAI-compatible | Configured `/chat/completions`-compatible endpoint | Preserved | Prompt Runtime sends one composed system message | Native strict schema request | Supported through provider SSE adapter | `response_format.type=json_schema`, strict schema | Kernel -> Preset -> Capability Policy -> Runtime Contract -> user request | Endpoint must implement the OpenAI-compatible strict-schema and SSE shapes it advertises; arbitrary configured provider names are not independently certified | Deterministic sync, stream, ordering and schema tests pass |
| GLM | OpenAI-compatible GLM endpoint | Preserved first | One composed AgentOS system message; transport schema instruction is appended to its content | JSON object mode plus schema compatibility instruction | Supported; reasoning activity remains private | `response_format.type=json_object` | Kernel -> Preset -> Capability Policy -> Runtime Contract -> `TRANSPORT OUTPUT CONTRACT` -> user request | Native strict JSON Schema is not used; schema is enforced by compatibility instruction plus local validation | Deterministic payload, reasoning, stream and ordering tests pass |
| Zhipu | Same explicit compatibility branch as GLM | Preserved first | Same as GLM | Same as GLM | Same transport implementation | Same as GLM | Same as GLM | No separate live endpoint certification was possible in the current environment | Deterministic branch coverage through provider alias; model-backed status not run |
| Other configured providers, including OpenAI, DeepSeek and local gateways | Generic OpenAI-compatible branch | Preserved | One upstream-composed system message | Assumed strict-schema compatible | Assumed SSE compatible when streaming is required | Generic strict schema | Same upstream authority ordering | Support depends on endpoint wire compatibility; no provider-specific semantics are inferred from the name | Generic adapter contract tested; vendor-specific live tests not run |
| `zhipuai` identifier | Generic model transport branch | Preserved | One upstream-composed system message | Generic strict schema attempt | Generic transport | Generic strict schema | Same upstream ordering | Retrieval routing recognizes `zhipuai`, but model transport's GLM compatibility branch currently recognizes only `glm` and `zhipu`; configure `zhipu` for that behavior or converge in a future provider change | Documented limitation; not certified |

## Identity semantics

`promptInstanceHash` includes normalized upstream messages, schema, provider family, model/version and behavior options. It also records the provider's structured-output mode so generic strict schema and GLM/Zhipu compatibility mode cannot collide. Request id, timeout, retry count, trace id and streaming transport mode are excluded. The provider adapter cannot redefine Kernel, Preset or Capability Policy; it may only add the schema transport contract after the composed trusted prefix.
